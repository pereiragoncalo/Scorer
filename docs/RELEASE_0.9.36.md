# Scorer World0.9.36 QA — official national fixtures only

National-team friendlies are no longer generated, offered as playable fixtures or
shown in the upcoming calendar. Loading an existing competition book removes
unplayed friendly fixtures, while preserving completed results, international caps
and goals, and all official national tournaments and qualifiers. Scheduling also
removes pending legacy friendlies still present in memory. The legacy Free path
no longer replaces a league match with a random national-team friendly.

Official call-up eligibility and national competitions stay available. Existing
training, injuries/recovery, club fixtures, dashboard and shot physics are unchanged.
Explicit recording of an already-started legacy friendly remains compatible; it
cannot create another friendly in the normal calendar.

This is an existing-debug-key QA build. Physical Android playtesting remains
pending. Previous official five-season club-table audit limitations remain.
Google Play production1.0 and the leaderboard server installer are unchanged.
