# Scorer World 1.0 (1030021)

Season leaderboard publication is immediate after the explicit per-season choice.
The companion backend upgrade publishes already-pending consented v5 seasons;
rejected/banned records remain hidden and earlier v3/v4 moderation is unchanged.
The app opens the submitted division, remembers the selected division and refreshes
when an offline authorized submission succeeds. No DOB/PIN fields are introduced.

Season review has aligned panels, fitted long names, compact match dates and a
consistent coach section, keeping the results, scorers, own position and next-season
objectives on one landscape screen. Nine languages remain supported.

Stationary blockers and waiting celebration teammates no longer run in place.

lateral penalties. Save geometry and ball/goal decisions remain physical.
