# Newspaper artwork and font

Five original AI-generated fictional sports photographs were created for this
feature on4 November2026 using the image-generation tool. No real players,
club identities, branding, sponsor marks or external sports photographs were
requested. The originals remain in the generation workspace; the following
unchanged PNG copies are bundled as offline miniature match illustrations.
Rotation is deterministic per played report, not per page opening.

Liberation Fonts package. The bundled `assets/fonts/Liberation.license` contains
the complete supplied copyright and SIL Open Font License text. Existing Noto
fonts handle CJK text; existing Barlow Condensed supplies the masthead.
