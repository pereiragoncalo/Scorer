# New upload key on the owner's bastion

Owner confirmed new Play app enrollment, with no previous app/release. The owner
explicitly authorized preparing the upload key and signed1.0 AAB. The private key
must remain under owner control; this cloud has no production key/password.

The standalone tools/play/create_upload_key.py uses only Python's standard library
and JDK keytool. On the owner's bastion, install default-jdk-headless if keytool or
jarsigner is absent, then download the pinned helper and verify its SHA256. Run:

```
python3 /tmp/scorer-create-upload-key.py --keystore /root/scorer-signing/scorer-upload.p12
```

Enter a NEW12+character password twice at the hidden prompts; use letters/numbers/
symbols/spaces without accents for PKCS12 compatibility. Password values never
appear in argv or shell history. The child JDK reads the password through an
environment selector. Do not enable shell tracing or paste secrets into chat.

Output files:

- /root/scorer-signing/scorer-upload.p12 — private encrypted upload identity,0600.
- /root/scorer-signing/scorer-upload.certificate.pem — public certificate.
- The dedicated signing directory is0700. Existing keys/certificates are refused;
  exclusive file links also prevent overwrites during concurrent creation.

Back up the .p12 and password securely in separate locations before Play enrollment.
Share only the public certificate or its SHA256 fingerprint. This is the upload
key, separate from the Google-generated app signing key for Play-installed builds.
