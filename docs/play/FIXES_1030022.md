# World1.0 /1030022 — finite net contact and defensive lines

Run on the existing bastion. No backend patch is needed. The same existing
upload key and service account are used; this publishes only to INTERNAL.

```bash
(
set -eu
scorer_release=$(mktemp -d /root/scorer-release.XXXXXX)
scorer_base=https://github.com/pereiragoncalo/Scorer/releases/download/world-1.0-1030022
curl -fL --retry 2 "$scorer_base/bastion_play_internal.py" -o "$scorer_release/uploader.py"
printf '%s  %s\n' 7b20b3270a03c50d62f01c2a23f4b6d1a0fb35dc761d6046fa68bf67499bc8c5 "$scorer_release/uploader.py" | sha256sum -c -
install -m700 "$scorer_release/uploader.py" /root/scorer-signing/play-internal.py
python3 /root/scorer-signing/play-internal.py --publish
python3 /opt/scorer/server/version_updates.py --minimum 0 --latest 1030022 --name 1.0
curl -f https://stats.clemir.com/v1/app-version
)
```

Confirm `Committed INTERNAL version1030022`, update through Play without
uninstalling/clearing data, then check the installed footer `v1.0 (1030022)`.
Check low/medium/high hard shots in triangular nets, glancing side-to-rear travel,
no pre-contact braking or added rebound energy, static actors standing still,
and a back four with three midfielders in ordinary opportunities. Penalties,
free-kick walls and genuine one-on-ones keep their special positioning.
